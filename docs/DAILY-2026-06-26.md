# 工作日报（2026-06-26）

## 一、Event Worker 碰撞日志

- **`services/event_engine/worker.py`**：新增可开关终端日志（`COLLISION_LOG=1`）。
  - 每帧有碰撞打印 **`[COLLISION][HIT]`**（含 `camera`、`frame_idx`、`hits`）。
  - 触发告警时再打印 **`[COLLISION][ALARM]`**（含 `alarms` 与当帧 `hits`）。
  - HIT 与 ALARM **独立输出**，不再因告警而跳过 HIT，**无 cooldown 节流**。
- **`event_worker.py`**：启动时提示「碰撞终端日志已开启」。
- 与 **`[CALLBACK][SEND]`** 区分：回调不依赖 `COLLISION_LOG`；日志仅便于本机联调对照 `frame_idx` 与连续帧门控。

## 二、监控页碰撞 / 事件矩阵对齐

- **根因**：legacy 扁平标注 JSON 后端 token 为 **`Box_{id}`**，前端从 `source_info` 注入 `shelf_code` 后 key 为 **`{shelf}:{id}`**，导致侧栏货位矩阵与 ROI 不着色。
- **`web/src/lib/annotation.js`**：`collisionMatchesBox` 兼容 `Box_*` 与 `shelf:box_id`；新增 `boxMatchesAnyCollision`。
- **`MonitorPreviewStage.jsx` / `.css`**：侧栏面板增加 **碰撞 N · 告警 N** 实时统计；告警格 **脉冲动画**；`resolveRoiState` 改用宽松匹配。
- **`MonitorPage.jsx`**：legacy WebSocket 网格绘制同步使用 `boxMatchesAnyCollision`。
- 前端已 **`npm run build`**（`v26.1.1.build250`）；本机 UI 需强刷或同步 `web/dist`。

## 三、本机 cam1 联调（Docker + conda）

- 基础设施：**Redis / MediaMTX** Docker；**UI / event_worker / inference_worker** 宿主机 Python（`visual-dps` conda）。
- 关键环境：`REDIS_HOST=127.0.0.1`、`RTSP_CAPTURE_BACKEND=opencv`（避免 ffmpeg cuda 读帧失败）；推理用环境变量对齐 `runtime_config`（`inference_worker` 不读 `runtime_config.json`）。
- **`localdata/runtime_config.json`**（本机）：`rtmpose_m`、`pose_frame_interval: 1`、height 240。
- 标注 **`cam1.json`**：`annotation_size` 640×360；推流分辨率需与标注一致，避免 ROI 视觉偏大。
- 数据流：`inference → pose:* → event_worker → event:* + Java 回调`；监控页 SSE 合并骨架与碰撞。

## 四、排查说明（文档级）

- **HIT 多、ALARM 少**：`collision.py` 连续 **`alarm_min_consecutive_frames`**（默认 3）+ **`alarm_cooldown_frames`**（配置 6）；中间漏帧会重置计数。
- **重启推理后骨架「超前」**：Redis 快照 TTL（约 10s）、`LiveHub` 内存缓存、HLS 比 RTSP 推理延迟大；非单一 frame_idx  bug。
- 碰撞核心代码路径：`event_engine/collision.py` → `worker.py` → `event_bus.py` → `live_bus.py`。

## 五、待办 / 风险

- 本机 **无 `visual-dps-ui` 容器** 时需直接跑 `uvicorn` + 本地 `web/dist`，改前端后勿忘 rebuild。
- **`COLLISION_LOG=1`** 高帧率下终端刷屏，联调完建议关闭。
- Java 回调 URL 指向 `127.0.0.1` 时 **`Connection refused`** 为预期（无 mock 服务）。
- 推理重启后若骨架异常：可 `DEL pose:snapshot:{cam} event:snapshot:{cam}` 并重启 UI 清 `LiveHub` 缓存；监控页优先 **MJPEG/WebRTC** 降低与骨架时延差。
