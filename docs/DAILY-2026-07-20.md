## 一、代码提交（已入库）

### 1. pick_prefilter 模块与 Event Worker 接入（`81307a7`）

**目标**：将 data-collector 已验证的 **碰撞前置门控** 接入生产 Event Worker，抑制取货误报（FP），默认关闭以保持 baseline。

**门控规则**（与离线标定一致）：

```text
block = ankle_max_speed_norm > 0.081770
    AND NOT triple90
    AND is_standing(shoulder_hip_knee_angle_min >= 140)
```

- **triple90（AND 豁免）**：`arm_torso_angle_max≥90`、`elbow_angle_mean≥150`、`wrist_elevation_angle_max≥60`
- **站立判定**：`shoulder_hip_knee_angle_min≥140`；**缺角度视为站立**（保守压 FP）
- **不含**末行货位排除

**新增模块** `services/event_engine/pick_prefilter/`：

| 文件 | 职责 |
|------|------|
| `config.py` | `PickPrefilterConfig`，默认 norm 阈值 **0.081770** |
| `features.py` | 流式 `IncrementalAggregateVelocityTracker`；**dt 优先 `pose.ts`**；墙钟 `max_pose_gap_sec` reset |
| `angles.py` | triple90 + shknee140 单帧角度 |
| `gate.py` | `_speed_high` + triple AND + stance 布尔逻辑 |
| `service.py` | `PickPrefilterGate.should_block()` |

**接入改动**：

- **`services/event_engine/collision.py`**：`CollisionPrefilterProtocol` 钩子；block 时跳过该人手腕 `pointPolygonTest`
- **`services/event_engine/worker.py`**：按 `collision_prefilter.enabled` 注入/热更新 prefilter；infer 重启（`frame_idx` 回绕）时 `prefilter.reset_session()`
- **`services/runtime_config_service.py`**：`collision_prefilter.*` 公开键 + `get_collision_prefilter_section()`

**生产化要点**（与离线 pipeline 差异）：

| 离线 data-collector | 生产 visual-dps |
|---------------------|-----------------|
| 完整 timeline + export 二次抽帧 interval=2 | Redis **逐 pose** 处理，禁止再抽帧 |
| `timestamp_sec` | Pose 仅有 wall-clock **`ts`**（`pose_bus.build_pose_frame`） |
| `MAX_VELOCITY_GAP_FRAMES=2` | **`max_pose_gap_sec`** 墙钟 reset（0=自动 `interval/fps×2.5`） |

**标定指标**（28 clip，`3793f19`）：TP=146、FN=10、FP=311、召回 **93.59%**（与 pixel `ankle@80` 重算一致）。
