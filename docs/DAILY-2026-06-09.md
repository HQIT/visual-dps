# 工作日报（2026-06-09）

## 一、Edge Node REST 接入（分支 `feat/edge-node-rest-ingest`）

### 背景

- 边缘设备（如 230 `visual-dps-edge`）需在本地做 pose，**禁止直连 Redis**；鉴权走 Keycloak Client Credentials。
- 画面长时间无人时 pose 不更新，需独立 **status** 上报表示 edge 存活（`idle` / `running` / `error`）。

### 中心 API（`/api/edge/v1/...`，Bearer JWT）

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `.../status` | Redis `edge:status:{cam}`，UI `edge_runtime`、拓扑 `EDGE_STATUS_STALE` |
| POST | `.../pose` | 内部 `publish_pose_frame()`，event-worker 碰撞（central 模式） |
| GET | `.../annotation` | ROI 只读 + `revision`/`updated_at`（Phase B） |
| POST | `.../events` | `publish_event_frame_dict()` + Java 回调（Phase B 边缘碰撞） |

- 鉴权：`AuthMiddleware` 对 `/api/edge/` bypass Session；路由内 JWKS 验 Bearer（`services/edge_auth.py`），非全局 JWT 中间件。
- 配置：`EDGE_API_ENABLED`、`EDGE_JWT_ISSUER` 等（`.env.example`、`localdata/edge_api_config.json.example`）。
- 依赖：UI 镜像增加 `PyJWT[crypto]`。

### 摄像头模型（兼容旧 `camera_ips.json`）

- 新字段：`inference_mode`（默认 `central`）、`edge_capabilities`（`pose` / `video` / `collision`）。
- `camera_store` 透传可选字段；`inference_mode=edge` 时禁止启中心 infer 容器。
- 仅 pose 的 edge 路：`external` 可不填 RTSP。

### Event / 拓扑 / UI

- **Phase B**：`edge_capabilities` 含 `collision` 时 event-worker **跳过**该路 pose 碰撞；边缘 `POST .../events`。
- 拓扑：edge 路看 status + pose；`state=idle` 不报 `POSE_STALE`。
- UI：检测来源、边缘能力勾选；卡片/抽屉显示边缘在线与状态文案。

### 文档

- `docs/EDGE-NODE-INTEGRATION.md`：接入说明书（REST、Keycloak、Phase A/B、最小接入说明）。
