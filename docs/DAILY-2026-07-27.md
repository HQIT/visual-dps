## 二、架构变更

### 1. `services/pipeline_log.py` 扩展为进程日志中枢

| Logger | 用途 | 输出条件 |
|--------|------|----------|
| `visual_dps.boot` | 启停、delivery 模式 | 始终 stdout |
| `visual_dps.inference` | 模型加载、RTSP、推理会话 | 始终 stdout |
| `visual_dps.pipeline` | `[PIPELINE]` 阶段 trace | `pipeline_log.enabled` + 采样 |
| `visual_dps.collision` | `[COLLISION][HIT/ALARM]` | `COLLISION_LOG` |
| `visual_dps.prefilter` | `[PREFILTER][PASS/FILTERED]` | `PREFILTER_LOG` / `COLLISION_LOG` |
| `visual_dps.callback` | `[CALLBACK][SEND/ACK/...]` | reporting.enabled |

新增 API：`configure_process_logging()`、`reload_process_logging()`、`get_*_logger()`；保留 `log_pipeline_stage` 等兼容接口。

### 2. 文件日志

- `FileHandler` → **`RotatingFileHandler`**
- 配置项：`pipeline_log.max_bytes`（默认 50MB）、`pipeline_log.backup_count`（默认 5）
- 同进程共用一个 `{dir}/{role}.log`（如 `worker.log`、`infer_cam1.log`）

### 3. 热更新

| 进程 | 机制 |
|------|------|
| event-worker | `_refresh_runtime_settings_if_needed` 内调用 `reload_process_logging` |
| infer 容器 | 主循环每 300 帧或 30s 检测 `runtime_config.json` mtime |

**限制**：变更日志目录或轮转参数时打 warning，需 **重启容器** 才切换 file handler；开关/采样可热更新。
